## [0.1.0] - 2026-08-21

### Added

- Initial public release of LitCurate: a config-driven literature-to-database pipeline
  (search, filter, PDF conversion, schema extraction, and export) with checkpoint and resume.
- GitHub Actions CI (lint + tests), tag-based GitHub Releases, and MkDocs documentation workflow.
